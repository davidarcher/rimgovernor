# Construction contract checkpoint

The canonical source is `integrations/RIMAPI/Contracts/construction.openapi.json` (OpenAPI 3.1). It defines operations, request bodies, success/error responses, bounds, enum states, nullability, and wire names. C# DTOs, strict Python domain models, and the embedded runtime manifest are generated from it with `python scripts/generate_native_models.py`. `--check` fails on generated drift. Tests validate the OpenAPI document with openapi-spec-validator.

The native API validates requests and responses against the generated manifest. Python consumes generated domain objects through NativeClient and checks response identities and state consistency. Construction tool responses retain their shape and explicit native pagination; they do not pass through the generic Python projection/compaction wrapper. Installed-contract drift stops integration rather than being silently accepted.

Endpoints cover buildable definitions, explored rooms, placement inspection, and placement commands. Definitions expose dimensions, work, costs and legal materials. Rooms expose visible cells and native reachability to a sample cell. Construction uses native placement legality checks, handles zero-work objects immediately, and reports ready/blueprint/frame/built/rejected with IDs and reasons. Repeat placement resolves existing blueprint/frame/building state. The integration owns completion tracking; the model does not author a construction completion query. The old blueprint draft tool is hidden when these contracts are installed.

Live regression `scripts/live_native_construction.py --execute --model` passed against the disposable game: `.rimbot/native-construction-tests/20260905-183431/report.json`. It verified strict malformed-request rejection, out-of-bounds and overlapping placement rejection, repeat placement identity, instant sleeping spot creation, and an actual model draft → administrator → native bed blueprint → readback. 30.86 seconds, five model calls, one model-issued order. The test supplies an inspected site and observed definition/material; it is not evidence of autonomous room layout or economic material choice. Test fixture placement selected silver; this is not production material policy.

Earlier failures are retained: HTTP response completion was fixed after connection timeouts; blueprint material identity was corrected to use Blueprint_Build.stuffToUse rather than Thing.Stuff. The full colony startup test has not been proven by this bounded regression.

50 backend tests and six dashboard tests passed. C# and dashboard builds succeeded; the native build retains its existing System.Runtime reference warning. The dashboard omits per-model-response “Review finished” rows and retains timings in export.

Remaining work: OpenAPI coverage and migration for the rest of RIMAPI; autonomous construction planning; optional camera following that yields to the player (native move/zoom endpoints exist, input/focus coordination is not implemented).
