RimGovernor

Acceptance cases

Runs one native acceptance case in a visible game window, on this checkout's game copy, so you can watch it. Stop the controller and close the game first. The first run installs the test build of the mod; it is replaced by the normal one once the game closes. A case that failed last time resumes from its checkpoint unless From scratch is ticked.
